# RECARRY Design System

## 1. Design Philosophy

RECARRY는 Premium Travel Brand처럼 보인다.

키워드:

- Premium
- Travel
- Circular
- Modern
- Editorial

---

## 2. Visual Principles

### Whitespace

콘텐츠를 화면에 과도하게 채우지 않는다.

### Typography

크기와 간격을 통해 위계를 만든다.

### Photography

강한 여행 이미지를 선택적으로 사용한다.

### Color

화이트 / 샌드 / 포레스트 / 다크를 중심으로 사용한다.

환경 관련 메시지를 표현할 때도
초록색을 남용하지 않는다.

## 9. Motion

Motion은 브랜드를 보조해야 한다.

사용 가능:

- fade
- slide
- scale
- parallax
- scroll progress
- image reveal

사용 금지:

- excessive bounce
- excessive glow
- constant movement
- unnecessary 3D effects
