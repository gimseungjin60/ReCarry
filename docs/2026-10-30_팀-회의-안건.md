## 2. 캐리어 렌탈 가격

지금 사이트의 가격은 **시연용 값**이다.

| 사이즈 | 기본 요금 (시연값) | 1박 추가 |
|---|---|---|
| 20" | 19,900원 | 4,000원 |
| 24" | 25,900원 | 5,000원 |
| 28" | 31,900원 | 6,000원 |

**제안 — 원가 기반으로 정하고, 경쟁사로 검증한다.**

```
1회 대여 원가 = (매입가 + 수리 · 부품비) ÷ 예상 대여 횟수
             + 왕복 택배비 + 세척 · 소모품 + 포장
             + 결제 수수료 (PG 를 쓰면 3% 안팎)
대여 요금   = 1회 대여 원가 × (1 + 목표 마진)
```

- [ ] 사이즈별 **중고 매입가** · 평균 수리비 (매입처별로 조사)
- [ ] 캐리어 1개가 몇 번 대여되면 은퇴할지 (예상 10~20회)
- [ ] 경쟁 렌탈 업체 3곳의 같은 사이즈 · 같은 박수 가격 조사 — 담당자 정하기
- [ ] 기본 요금에 포함되는 박수, 1박 추가 요금
- [ ] 첫 오픈 할인을 할지 (하면 기간 · 할인율)

- [ ] 보증금 **대여 요금의 30%** 유지할지 (지금 정책)

## 5. 결제 방식

| 방안 | 초기 · 고정비 | 건당 비용 | 장점 | 단점 |
|---|---|---|---|---|
| **A. 무통장 입금 유지** (지금) | 0원 | 0원 | 이미 구현 완료, 계좌만 넣으면 끝 | 입금 확인 · 환불 송금이 수작업, 고객 이탈 (카드 결제를 원하는 고객) |
| **B. 토스페이먼츠 직접 연동** | 가입비 · 연관리비 있음 (프로모션 면제 사례 있음, 견적 필요) | 카드 수수료 3%대 + VAT, 영세 · 중소 사업자는 우대 수수료 자동 환급 | 카드 · 간편결제(토스페이 · 카카오페이 등), 에스크로, 부분 환불 | 사업자등록 후 심사, 개발 3~5일 |
| **C. 포트원(PortOne) 경유** | 포트원 자체는 소규모 무료 구간 있음 + 연결한 PG 비용 | PG 와 동일 | 나중에 PG 를 바꾸기 쉬움 | 한 단계 더 거침 |

**제안:**
1. **오픈은 A (무통장)** — 추가 비용 0원, 이미 작동한다. 대신 실제 계좌(`BANK_*`) 만 정한다
2. 사업자등록이 나오면 **B (토스페이먼츠) 견적 · 심사**를 바로 신청 → 첫 달 예약이 생기면 붙인다
3. PG 심사 때 확인할 것: **렌탈 업종 · 보증금(부분 환불) 처리** 가능 여부, 에스크로 제공 여부

결정할 것:
- [ ] 입금 계좌 (사업자 계좌 은행 · 예금주)
- [ ] PG 를 언제 붙일지, 어느 회사로 견적 받을지

## 6. 서버 · DB 요금제

지금은 모두 **무료 플랜**이다. 문제:

- **Vercel(프론트) 무료(Hobby)는 상업적 사용 금지** — 돈을 받는 순간 약관 위반이다
- Render(백엔드) 무료는 15분 미사용 시 잠든다 (지금은 10분마다 깨우는 임시 처리)
- Supabase(DB) 무료는 미사용 시 일시정지되고, **자동 백업이 없다** (고객 · 예약 데이터 유실 위험)

| 방안 | 구성 | 월 비용 (추정) | 장점 | 단점 |
|---|---|---|---|---|
| **A. 지금 구성 그대로 유료** | Vercel Pro $20 + Render Starter $7 + Supabase Pro $25 | **약 $52 (≈ 7.3만 원)** | 코드 변경 0, 일일 백업 | 셋 중 가장 비쌈 |
| **B. 프론트를 백엔드에 합치기** | Render Starter $7 + Supabase Pro $25 (Vercel 제거) | **약 $32 (≈ 4.5만 원)** | 연 약 $240 절약, 서버 하나라 관리 단순 | 개발 하루 (빌드 · 배포 구조 변경), 화면 로딩이 CDN 보다 조금 느릴 수 있음 |
| **C. 최소 비용 (테스트 오픈용)** | Render Starter $7 + Supabase 무료 + 매일 자동 백업(GitHub Actions) + 프론트 B 방식 | **약 $7 (≈ 1만 원)** | 거의 무료 | Supabase 일시정지 · 용량 위험, 공식 지원 없음 |
| D. 국내 클라우드 (AWS 서울 · NCP 등 서버 1대에 DB 까지) | VM 1대 | 약 1~3만 원 | 한국에서 빠름, 데이터 국내 보관 (개인정보 국외 이전 고지 불필요) | 서버 · DB · 백업 · 보안 패치를 직접 관리 → 지금 팀 규모에 부담 |

**제안:**
- 정식 오픈 전 (지인 테스트 기간): **C**
- 실제 고객 결제를 받기 시작하면: **B** — 월 약 4.5만 원. 백업이 되는 DB(Supabase Pro)는 고객 데이터 때문에 아끼지 않는다
- 트래픽이 커지거나 데이터 국내 보관이 필요해지면 그때 D 를 검토한다

결정할 것:
- [ ] 방안 선택, 결제 카드 · 계정 소유자 (팀 공용 계정 권장)
- [ ] 월 예산 상한
