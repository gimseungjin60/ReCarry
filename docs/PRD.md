# RECARRY Web MVP — PRD

## 1. Product

RECARRY

버려지는 캐리어를 다시 여행으로.

RECARRY는 폐기 예정 캐리어를 회수한 뒤
세척·수리·검수하여 다시 렌탈하는
자원순환형 캐리어 렌탈 서비스다.

---

## 2. MVP Goal

이번 웹 MVP의 목적:

- RECARRY 서비스 이해
- 브랜드 경험 전달
- 캐리어 상품 탐색
- 캐리어 상세 확인
- 예약 흐름 체험

실제 결제나 실제 배송 운영을 구현하는 것이 목적이 아니다.

---

## 3. User Journey

Home
→ Collection
→ Product
→ Booking
→ Complete

## 5. RECARRY Differentiators

일반 캐리어 렌탈과 차별되는 핵심 요소:

### Carrier Story

하나의 캐리어가

회수
→ 수리
→ 세척
→ 검수
→ 새로운 여행

을 거치는 과정을 보여준다.

### Carrier ID

각 캐리어를 개별 자산처럼 보여준다.

### Inspection

고객에게 검수 완료 상태를 보여준다.

### Circular Journey

캐리어의 한 번의 여행으로 끝나지 않는
순환 구조를 강조한다.
