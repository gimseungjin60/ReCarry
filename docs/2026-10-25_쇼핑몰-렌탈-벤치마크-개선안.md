## 2. 장바구니를 넣을까? — 넣지 않는다

캐리어 렌탈은 "한 번의 여행 = 한 번의 예약"이다. 여러 상품을 모았다가 한 번에 결제하는 장바구니가 맞지 않는다. 날짜마다 재고가 달라 담아 두는 동안 품절될 수도 있다.

대신 장바구니의 장점만 가져왔다.
- **담아 둔 것이 사라지지 않는다** → 예약 중이던 내용(사이즈 · 날짜 · 배송 정보)을 같은 탭에서 자동 보관하고, 로그인 · 가입을 다녀오면 그대로 이어진다.
- **결제 직전에만 로그인** → 쇼핑몰의 "주문하기 → 로그인/간편가입" 순서와 같다.

비회원 주문은 하지 않는다. 입금 확인 · 환불 · 보증금 반환 연락을 위해 계정이 필요하고, 카카오 간편가입으로 부담을 낮췄다.

## 3. 바뀐 사용자 흐름

```
홈 (사이즈 · 날짜) ─┐
상품 상세 (옵션 · 날짜 · 결제 예정 금액) ─┤
                    ▼
예약 1 날짜 → 2 캐리어 → 3 배송 정보(주소 검색 · 최근 배송지) → 4 예약 확인
                    ▼  "로그인하고 예약 요청" (비회원일 때)
     [카카오로 3초 만에 계속하기] / [이메일로 로그인] / [회원가입(인증번호)]
                    ▼  (고른 내용 그대로 복귀)
예약 요청 완료 → 무통장 입금 안내 (화면 · 메일)
                    ▼
관리자 입금 확인 → 확정 메일 → 출발 전날 배송 → 여행 → 회수 → 보증금 정산 메일
```

카카오 가입 흐름:
- 처음 오는 사람: 카카오 동의 → 우리 가입서(카카오 정보로 채워짐, 약관 동의만) → 원래 화면으로
- 같은 이메일 회원: 카카오 동의 → 기존 계정에 연결되어 바로 로그인
- 이미 연결된 회원: 카카오 동의 → 바로 로그인

## 5. DB 는 무엇으로? — 지금 그대로 (PostgreSQL · Supabase)

결론: **바꾸지 않는다.** PostgreSQL 은 예약 겹침을 DB 제약(배타 제약)으로 막을 수 있어 렌탈에 특히 맞다. 이 기능은 MySQL 에는 없다.

| 단계 | 권장 | 비용 |
|---|---|---|
| 지금 (오픈 전 ~ 초기) | Supabase Free + keepalive (일시정지 방지) | 0원 |
| 정식 오픈 · 실제 결제 시작 | **Supabase Pro** — 일시정지 없음, 매일 백업, 더 큰 연결 한도 | 월 $25 |
| 같은 시점 서버 | Render Starter — 잠들지 않음 (keepalive 불필요) | 월 $7 |
| 트래픽이 커지면 | 같은 PostgreSQL 그대로 사양만 올림 (코드 변경 없음) | — |

바꾸지 않는 이유:
- 스키마 · migration(Flyway) · 테스트가 모두 PostgreSQL 기준이다.
- RLS 로 외부 Data API 를 막아 두었다.
- 서울 리전이라 국내 응답이 빠르다.

## 6. 도메인을 사면 할 일 (키만 넣으면 끝나게 준비함)

1. Vercel 에 도메인 연결
2. Render 환경변수:
   - `APP_URL=https://새도메인` (메일 링크 · 카카오 Redirect URI 가 이 값으로 만들어진다)
   - `CORS_ALLOWED_ORIGINS` 에 새 도메인 추가
3. 카카오 개발자 콘솔:
   - 앱 생성 → 카카오 로그인 켜기
   - Redirect URI `https://새도메인/api/auth/kakao/callback` 등록
   - 동의 항목(이메일 · 이름 · 휴대폰 번호) 설정
   - REST API 키 · Client Secret 을 Render 의 `KAKAO_CLIENT_ID` · `KAKAO_CLIENT_SECRET` 에 넣기
4. Brevo:
   - 새 도메인으로 발신 인증 (SPF · DKIM)
   - `MAIL_API_KEY` · `MAIL_FROM` 설정
5. `.github/workflows/keepalive.yml` 의 주소를 새 도메인으로

키가 없으면 카카오 버튼이 자동으로 숨고, 메일 설정이 없으면 인증번호 단계가 자동으로 빠진다. 그래서 설정 전에도 사이트는 정상 작동한다.
