# RECARRY 운영 정책 — 결정 기록

> 화면에 보이는 정책 전문은 `src/data/legal.ts` (이용약관 · 개인정보 처리방침 · 대여 정책).
> 코드가 쓰는 정책 값은 `backend/src/main/resources/application.yml` 의 `recarry.booking.*` · `recarry.legal.*`.
> 정책을 바꾸면 이 문서 → legal.ts → application.yml 순서로 함께 고치고, 문서 시행일(버전)을 올린다.
> **모든 문서는 정식 서비스 전 법률 검토가 필요한 초안이다.**

## 확정 (2026-10-20, 대표 결정)

| 항목 | 결정 | 코드 반영 |
|---|---|---|
| 1인 예약 수 제한 | 없음 | 제한 로직 없음 |
| 예약 요청(REQUESTED) 유효 기간 | 접수 후 **3일** 안에 확정되지 않으면 자동 취소 (추후 변경 가능). 시행일(2026-10-20) 이전 요청에는 적용하지 않음 | `request-expiry-days: 3`, `request-expiry-from`, `BookingExpiry` (기동 시 + 5분마다) · 취소 사유 `EXPIRED` |
| 보증금 | **대여 요금의 30%**, 100원 미만 버림. 대여 요금과 별도로 받고 반납 검수 후 환불 | `deposit-percent: 30`, `bookings.deposit` 스냅샷 |
| 결제 후 환불 | 가능 | 결제(PG) 미구현 — 정책 문서만 |
| 취소 수수료 | 별도 수수료 없이 **보증금으로 대체** (배송 예정일 2일 전부터 취소 시 보증금 공제) | 결제 도입 시 구현 |
| 캐리어 조달 | 공항 회수 제휴 불가 → **중고 캐리어 매입** 방식으로 진행 | 화면 문구 "공항·호텔·가정에서 수거" 제거 → 매입·입고 표현 |
| 반납 후 세척 · 검수 버퍼 | **보류** | 버퍼 0일 그대로 (반납 다음 날 재배송 가능 — 운영자가 운영 상태로 관리) |

## PM 결정 (대표 위임, 변경 가능)

| 항목 | 결정 | 이유 |
|---|---|---|
| 취소·환불 단계 (2026-10-23 개정) | 결제 전 무료 · 결제 후 24시간 이내 또는 배송 3일 전까지 전액 · 배송 2일 전~배송 전 대여 요금 전액 환불 + 보증금 공제(30%) · 배송 후~사용예정일 전 대여 요금 80% 공제 · 사용예정일 이후 환불 없음 | 소비자분쟁해결기준 「단기 물품대여서비스업」(3일 전 50%, 1일 전 80%, 당일 100% 공제 허용)보다 같거나 유리. 처음 안(배송 후 100%)은 기준(1일 전 80%)을 넘어 고쳤다 |
| 회사 사정 취소 (2026-10-23 추가) | 같은 사이즈 대체 제안 → 원하지 않으면 전액 환불 + 대여 요금 배상 (7일 전 10% · 5일 전 30% · 3일 전 50% · 1일 전 80% · 당일 100%) | 소비자분쟁해결기준 「단기 물품대여서비스업」 업체 귀책 기준과 같다 |
| 보증금 환불 시점 | 반납 검수 완료 후 영업일 3일 이내 | |
| 파손 | 정상 사용 흔적은 청구 없음. 기능 파손은 수리 실비를 보증금에서 공제, 초과분 청구 | |
| 분실 · 수리 불가 | 사이즈별 배상 기준액 청구 (금액은 정식 서비스 전 확정) | 캐리어 매입가가 정해져야 정할 수 있다 |
| 연체 | 1일당 해당 사이즈 1박 추가 요금. 연락 없이 7일 초과 시 분실로 처리 | |
| 탈퇴 | 진행 중(확정 · 이용 중) 예약이 있으면 불가. 관리자 계정은 탈퇴 불가. 탈퇴 즉시 회원 정보 비식별화, 결제 전 끝난 예약(고객 취소 · 기한 만료 · 운영자 거절)의 배송 정보 삭제, 확정 이후 거래 기록은 법정 기간 보관 | 전자상거래법 보관 의무 |
| 비밀번호 변경 | 다른 기기의 로그인 모두 해제 | |
| 권한 변경 | 기존 토큰 즉시 무효 (다시 로그인) | |
| 기존 회원 재동의 | 시행 중인 문서 버전에 동의하지 않은 일반 회원은 로그인 후 보호된 화면에서 `/consent` 로 이동, 동의 전에는 예약 불가(서버 403 `CONSENT_REQUIRED`). 동의 대신 탈퇴 가능. 관리자는 제외 | 바뀐 약관(보증금 · 만료 · 환불)을 모르는 채 예약하지 않게 한다 |

## 정식 서비스 전 확정 필요

- 사업자 정보: 상호 · 대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 고객센터 연락처
- 개인정보 보호책임자 연락처
- Supabase 프로젝트 리전 (개인정보 국외 이전 고지)
- 배송 · 회수 방식, 배송비, 배송 가능 지역
- 분실 · 수리 불가 시 사이즈별 배상 기준액
- PG 결제 수단과 환불 처리 기간
- 법률 검토 — 2026-10-23 벤치마크(전자상거래 표준약관 · 소비자분쟁해결기준 단기 물품대여서비스업 · 개인정보 처리방침 작성지침 2025)로 문서를 보완했다. 정식 오픈 전 변호사 확인 권장
