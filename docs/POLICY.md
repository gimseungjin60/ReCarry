# RECARRY 운영 정책 — 결정 기록

> 화면에 보이는 정책 전문은 `src/data/legal.ts` (이용약관 · 개인정보 처리방침 · 대여 정책).
> 코드가 쓰는 정책 값은 `backend/src/main/resources/application.yml` 의 `recarry.booking.*` · `recarry.legal.*`.
> 정책을 바꾸면 이 문서 → legal.ts → application.yml 순서로 함께 고치고, 문서 시행일(버전)을 올린다.
> **모든 문서는 정식 서비스 전 법률 검토가 필요한 초안이다.**

## 확정 (2026-10-20, 대표 결정)

| 항목 | 결정 | 코드 반영 |
|---|---|---|
| 1인 예약 수 제한 | 없음 | 제한 로직 없음 |
| 예약 요청(REQUESTED) 유효 기간 | 접수 후 **3일** 안에 확정되지 않으면 자동 취소 (추후 변경 가능). 시행일(2026-10-20) 이전 요청에는 적용하지 않음 | `request-expiry-days: 3`, `request-expiry-from`, `BookingExpiry` (기동 시 + 5분마다) · 취소 사유 `EXPIRED` |
| 보증금 | **대여 요금의 30%**, 100원 미만 버림. 대여 요금과 별도로 받고 반납 검수 후 환불 | `deposit-percent: 30`, `bookings.deposit` 스냅샷 |
| 결제 후 환불 | 가능 | `Refunds` (고객 취소 시 서버가 환불액 계산) · 운영자가 송금 후 '환불 송금 완료' |
| 취소 수수료 | 별도 수수료 없이 **보증금으로 대체** (배송 예정일 2일 전부터 취소 시 보증금 공제) | `Refunds.customerCancelRefund` |
| 캐리어 조달 | 공항 회수 제휴 불가 → **중고 캐리어 매입** 방식으로 진행 | 화면 문구 "공항·호텔·가정에서 수거" 제거 → 매입·입고 표현 |
| 반납 후 세척 · 검수 버퍼 | **보류** | 버퍼 0일 그대로 (반납 다음 날 재배송 가능 — 운영자가 운영 상태로 관리) |

## 정식 서비스 전 확정 필요

- 사업자 정보: 상호 · 대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 고객센터 연락처
- 개인정보 보호책임자 연락처
- Supabase 프로젝트 리전 (개인정보 국외 이전 고지)
- 배송 · 회수 방식, 배송비, 배송 가능 지역
- 분실 · 수리 불가 시 사이즈별 배상 기준액
- **입금 계좌** — 지금은 임시 계좌. 사업자 계좌가 생기면 Render 환경변수 `BANK_NAME` · `BANK_ACCOUNT` · `BANK_HOLDER` 만 넣으면 된다 (코드 변경 없음)
- PG 결제 — 2026-10-23: 토스페이먼츠 가맹 심사 신청함, 도입 여부는 팀 논의 후 결정. 사업자등록번호는 추후 등록. 그전까지 무통장 입금(2026-10-25 구현)
- 휴대폰 SMS 인증 — 추후 도입 (유료 · 발신번호 등록 필요)
- 법률 검토 — 2026-10-23 벤치마크(전자상거래 표준약관 · 소비자분쟁해결기준 단기 물품대여서비스업 · 개인정보 처리방침 작성지침 2025)로 문서를 보완했다. 정식 오픈 전 변호사 확인 권장
